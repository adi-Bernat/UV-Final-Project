## 1. מבוא

UV | נגרות חוץ הוא אתר אינטרנט שנבנה עבור עסק המתמחה בתכנון וביצוע עבודות נגרות חוץ, ובהן פרגולות, דקים, גדרות, מחסנים, קירויי סנטף וחידוש עבודות עץ.

האתר משלב תצוגת פרויקטים ללקוחות עם מערכת ניהול המאפשרת לבעלי העסק לנהל מידע, משתמשים, פניות והצעות מחיר.

הפרויקט פותח בטכנולוגיות Full Stack תוך הפרדה בין צד הלקוח, צד השרת ומסד הנתונים.

## 2. מטרות הפרויקט

מטרות המערכת הן:

- יצירת נוכחות דיגיטלית מקצועית לעסק.
- הצגת השירותים והפרויקטים ללקוחות פוטנציאליים.
- מתן אפשרות להרשמה והתחברות לאתר.
- מתן אפשרות לשמירת פרויקטים מועדפים.
- יצירת מערכת לניהול משתמשים והרשאות.
- ניהול פניות לקוחות.
- יצירה, שמירה וניהול של הצעות מחיר.
- מתן אפשרות לעדכון פרופיל אישי ותמונת פרופיל.
- אבטחת מידע באמצעות אימות משתמשים ובדיקת הרשאות.

## 3. קהלי יעד וסוגי משתמשים

### אורח באתר

אורח שאינו מחובר יכול לצפות בעמודי האתר הציבוריים, להתרשם מהפרויקטים, לקרוא על העסק, ליצור קשר ולהירשם.

### משתמש רשום

משתמש בעל חשבון יכול להתחבר, לצפות בפרטים האישיים שלו, לעדכן שם ואימייל, להעלות תמונת פרופיל ולשמור פרויקטים מועדפים.

משתמש ששכח את סיסמתו יכול לבקש קישור לאיפוס סיסמה דרך האימייל הרשום במערכת.

### מנהל מערכת

מנהל יכול להיכנס למערכת הניהול ולבצע פעולות כגון:

- ניהול פרויקטים.
- ניהול משתמשים והרשאות.
- צפייה בפניות לקוחות ועדכון סטטוס.
- יצירה וניהול של הצעות מחיר.

הפעולות המוגנות מחייבות אימות הרשאות בצד השרת.

## 5. מבנה המערכת

המערכת מחולקת לשלושה חלקים עיקריים:

### Frontend

ממשק המשתמש שנבנה באמצעות React ו־TypeScript.

כולל את עמודי האתר, תפריט הניווט, הטפסים, הגלריות ומערכת הניהול.

### Backend

שרת שנבנה באמצעות Node.js ו־Express.

אחראי על קבלת בקשות API, אימות משתמשים, בדיקת הרשאות, טיפול בקבצים ותקשורת עם מסד הנתונים.

### Database

מסד נתונים מסוג MongoDB, המשמש לשמירת המידע העסקי ונתוני המשתמשים.

**תהליך התקשורת:**

Frontend → REST API → Backend → MongoDB

השרת מחזיר תשובות בפורמט JSON, והממשק מציג אותן למשתמש.

## 6. תיאור מסכי האתר

### דף הבית

מציג את שם העסק, תיאור השירותים וקישורים לצפייה בפרויקטים ולהרשמה.

### עמודי פרויקטים

מציגים פרויקטים לפי קטגוריות, תמונות, סרטונים ופרטי עבודות.

המערכת כוללת אפשרויות חיפוש וסינון.

### עמוד הרשמה והתחברות

מאפשר יצירת חשבון משתמש והתחברות לחשבון קיים.

מערכת ההתחברות תומכת במשתמשים רגילים ובמנהלים.

### עמוד מועדפים

מציג פרויקטים שהמשתמש שמר כמועדפים.

### עמוד הפרופיל האישי

מאפשר למשתמש מחובר לעדכן את שמו, כתובת האימייל ותמונת הפרופיל שלו.

התמונה נשמרת בתיקייה מקומית בשרת, והנתיב שלה נשמר במסד הנתונים.

### עמוד שכחתי סיסמה

מאפשר למשתמש לבקש קישור לאיפוס סיסמה באמצעות האימייל.

### עמוד יצירת סיסמה חדשה

מאפשר הגדרת סיסמה חדשה לאחר בדיקת קישור איפוס חד־פעמי בעל תוקף מוגבל.

### לוח הבקרה למנהל

מציג קישורים לניהול פרויקטים, משתמשים והצעות מחיר, לצד פניות שהתקבלו מהאתר.

### ניהול משתמשים

מציג רשימת משתמשים ומאפשר עדכון פרטים, שינוי הרשאות ומחיקה בהתאם להרשאות המנהל.

### ניהול פרויקטים

מאפשר הוספה, עריכה ומחיקה של פרויקטים.

### מערכת הצעות מחיר

מאפשרת יצירת הצעות מחיר, חישובי עלויות, שמירת הצעות, יצירת PDF והצגת הצעות ללקוחות.

## 7. מבנה מסד הנתונים

הפרויקט משתמש במספר מודלים עיקריים.

| מודל | מידע נשמר |
|---|---|
| User | שם, אימייל, סיסמה מגובבת, הרשאה ותמונת פרופיל |
| Admin | פרטי חשבונות מנהל ותיקים |
| Project | פרטי הפרויקט, קטגוריה, תיאור ומדיה |
| ContactMessage | פרטי פנייה, הודעה וסטטוס טיפול |
| UserFavorite | קשר בין משתמש לפרויקט מועדף |
| Quote | נתונים המשמשים לשמירת הצעות מחיר |

המערכת משתמשת במזהי MongoDB מסוג ObjectId לקישור וזיהוי רשומות.

## 8. ממשקי API

דוגמאות לנתיבים המשמשים את המערכת:

| Method | Endpoint | תפקיד |
|---|---|---|
| POST | `/api/register` | הרשמת משתמש |
| POST | `/api/users/login` | התחברות משתמש |
| POST | `/api/users/forgot-password` | בקשת איפוס סיסמה |
| POST | `/api/users/reset-password` | הגדרת סיסמה חדשה |
| GET | `/api/users/profile` | קבלת פרופיל אישי |
| PATCH | `/api/users/profile` | עדכון פרטים |
| POST | `/api/users/profile/image` | העלאת תמונה |
| GET | `/api/projects` | קבלת פרויקטים |
| GET | `/api/admin/users` | קבלת משתמשים לניהול |
| PATCH | `/api/admin/users/:id/role` | שינוי הרשאות |

פעולות המיועדות למשתמשים מחוברים או למנהלים מוגנות באמצעות Middleware בשרת.

## 9. אבטחת מידע

המערכת כוללת מספר מנגנוני אבטחה:

- שמירת סיסמאות באמצעות Hash ולא כטקסט גלוי.
- שימוש ב־JWT לצורך אימות התחברות.
- הפרדה בין הרשאות משתמש רגיל ומנהל.
- אימות הרשאות בצד השרת.
- בדיקות תקינות לנתונים.
- הגבלת כמות בקשות לשרת.
- בדיקת סוג וגודל של תמונות פרופיל.
- שימוש בקישורי איפוס סיסמה חד־פעמיים ובעלי תוקף מוגבל.
- שמירת מפתחות וסיסמאות בקובצי סביבה שאינם נכללים במאגר הציבורי.

לפני פריסה לשרת ציבורי נדרשות בדיקות אבטחה נוספות, לרבות ביטול התחברויות ישנות לאחר איפוס סיסמה ואימות כתובת אימייל חדשה בעת שינוי פרטי חשבון.

## 11. התקנה והרצה

יש להתקין Node.js ולהגדיר חיבור MongoDB.

### הפעלת Backend

```bash
cd backsite
npm install
npm run dev
```

### הפעלת Frontend

```bash
cd frontsite
npm install
npm run dev
```

יש להגדיר משתני סביבה מתאימים בקובץ `.env` על פי צורכי השרת.

כתובות סביבת הפיתוח:

- Frontend: `http://localhost:5173`
- Backend: `http://localhost:3000`
