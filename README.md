# UV | נגרות חוץ

## תיאור הפרויקט

UV | נגרות חוץ הוא אתר אינטרנט לעסק המתמחה בתכנון וביצוע עבודות נגרות חוץ, כגון פרגולות, דקים, גדרות, מחסנים, קירויי סנטף וחידוש עבודות עץ.

הפרויקט פותח במסגרת לימודי פיתוח Full Stack ב־HackerU.

האתר מאפשר ללקוחות להכיר את העסק, לצפות בפרויקטים, להירשם, לשמור פרויקטים מועדפים וליצור קשר. בנוסף, קיימת מערכת ניהול המאפשרת למנהלי האתר לנהל פרויקטים, משתמשים, פניות לקוחות והצעות מחיר.

## טכנולוגיות

**Frontend:**
- React
- TypeScript
- HTML5 ו־CSS3
- React Router
- Axios

**Backend:**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT לאימות משתמשים
- bcryptjs להצפנה חד־כיוונית של סיסמאות
- Joi לבדיקת נתונים
- Multer להעלאת תמונות
- Nodemailer לשליחת מיילים

## מבנה הפרויקט

הפרויקט מחולק לשתי תיקיות עיקריות:

**frontsite** – צד הלקוח, הכולל את רכיבי React, העמודים, קובצי CSS, התמונות ומערכת הניווט.

**backsite** – צד השרת, הכולל את נתיבי ה־API, המודלים, חיבור למסד הנתונים, אימות משתמשים והעלאת קבצים.

## בסיס הנתונים

המערכת משתמשת ב־MongoDB לשמירת נתונים כגון:
- משתמשים ופרטי חשבונות.
- הרשאות משתמשים.
- פרויקטים וקטגוריות.
- פרויקטים מועדפים.
- פניות לקוחות.
- הצעות מחיר.

תמונות הפרופיל נשמרות בתיקייה מקומית בשרת, והנתיב שלהן נשמר במסד הנתונים.

## התקנה והפעלת הפרויקט

### דרישות מקדימות

יש להתקין Node.js ולהגדיר חיבור למסד נתונים MongoDB.

### הפעלת השרת

יש לפתוח טרמינל בתיקיית `backsite` ולהריץ:

```bash
npm install
npm run dev
```

### הפעלת האתר

יש לפתוח טרמינל נוסף בתיקיית `frontsite` ולהריץ:

```bash
npm install
npm run dev
```

פקודות ההפעלה מניחות שקיים סקריפט `dev` בקובצי `package.json`.

בסביבת הפיתוח המקומית האתר פועל בדרך כלל בכתובת:

`http://localhost:5173`

והשרת בכתובת:

`http://localhost:3000`

## משתני סביבה
